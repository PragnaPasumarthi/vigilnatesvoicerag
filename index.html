Capabilities

Built for Real-World RAG

Not a toy demo. A production-grade pipeline with proper orchestration, structured I/O, and battle-tested guardrails.

🎙️

Voice Transcription

ElevenLabs scribe_v1 for high-fidelity speech-to-text. Supports WAV, MP3, and streaming. Mock STT for offline testing.

🧩

5-Strategy Chunking

Fixed-size, sliding window, recursive, semantic, and metadata-aware chunking — all running in parallel with Jaccard deduplication.

⚡

Sub-200ms Retrieval

Numpy cosine similarity with 128-dim word-hash embeddings. Vector store handles 2,706 chunks in under 0.2ms per query.

🔧

Pipeline Harness

Retry with exponential backoff, fallback handlers, structured I/O validation, per-step telemetry — not a raw prompt-in-text-out call.

🛡️

Multi-Layer Guardrails

Unsafe input blocking, IDF-weighted off-topic detection, hallucination checking via word grounding, and graceful refusal generation.

📊

Latency Analytics

P50/P70/P90/P95/P100 percentiles across 50 queries with warmup runs. Per-component breakdown: guardrails, retrieval, generation.

Deep Dive

5 Chunking Strategies, One Pipeline

Each strategy has unique trade-offs. The pipeline runs all five, deduplicates, and indexes the result for maximum retrieval coverage.

Metadata-Aware

Architecture

Pipeline Under the Hood

Every step is instrumented, retryable, and fallback-aware.

01

Ingest

Load passages, run 5 chunking strategies, deduplicate

02

Embed

128-dim word-hash vectors, L2-normalized

03

Index

Numpy matrix store with batch cosine similarity

04

Validate

Input guardrails: unsafe + off-topic checks

05

Retrieve

Top-k cosine similarity, score-ranked results

06

Generate

Extractive answer from top chunk context

07

Guard

Output grounding check, refusal if ungrounded
